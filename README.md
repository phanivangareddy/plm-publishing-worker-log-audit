# PublishLens

**by Phani Vanga**

PublishLens reads publishing logs from Windchill visualization workers. It shows how many documents were published, which ones failed, why they failed, and where the time went.

It runs only on your own Windows PC. It needs no internet connection, sends nothing anywhere and uses no AI service.

This repository holds the installer and the user guide only, with no source code.

## Download

**[Download PublishLens-1.0-Windows.zip](https://github.com/phanivangareddy/publishlens-setup/releases/latest/download/PublishLens-1.0-Windows.zip)** (about 9.6 MB), or see [all releases](../../releases).

## Get started

1. Download **PublishLens-1.0-Windows.zip**.
2. Right-click it and choose **Properties**. If you see **Unblock**, tick it.
3. Extract it to a local folder, such as `C:\PublishLens`.
4. Double-click **PublishLens.exe**, and keep the black window open while you use it.
5. In your browser, click **Add folder**, choose your log folder, then click **Analyse logs**.

Windows may warn that PublishLens is from an unknown publisher. Choose **More info**, then **Run anyway**, if your company allows it.

For full instructions, read the [user guide (PDF)](PublishLens-User-Guide.pdf).
